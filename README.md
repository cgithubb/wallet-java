Wallet application 

Vanilla Java application CMD

Commands available:
createwallet, transferamount, overview, statement, offer

Commands explaination
* createwallet <wallet_name> <init_amount>
-> creates wallet with the name and some initial balance in it.
* transferamount <sender_wallet_name> <receiver_wallet_name> <amount>
-> send amount from one wallet to another and also make note in transactions
* overview
-> lists all the wallets and amounts in.
* statment <wallet_name>
-> shows the statement transaction of the wallet
* offer<number>
-> applies available offer as per the number
